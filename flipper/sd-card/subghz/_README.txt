==============================
 SUB-GHz  (radio 300-928 MHz)
==============================
Gates, garage/car remotes, doorbells,
pagers, RF outlets, tire + weather sensors.

BUILT-IN (Sub-GHz menu)
- Read ............ capture a signal
- Frequency Analyzer  find a remote's freq
- Read RAW ........ capture anything (no decode)
- Saved ........... replay what you saved

APPS (Apps > Sub-GHz)
- Spectrum Analyzer  live RF activity graph
- ProtoView ........ decode unknown signals
- Sub-GHz Bruteforcer  try many codes (gates)
- Sub-GHz Playlist . fire many saved signals
- TouchTunes ....... bar jukebox control
- TPMS Reader ...... read car tire sensors
- Weather Station .. read 433MHz weather sensors
- POCSAG Pager ..... decode pager messages

COPY A REMOTE (fixed-code only)
1. Frequency Analyzer: hold remote to Flipper,
   press it -> note the freq (often 315/433)
2. Read on that freq, press the remote
3. Save -> Saved > Send to replay
Same code each press = fixed = it works.
Code changes, or says KeeLoq / Security+ /
Nice FloR-S = ROLLING code = replay won't open.
